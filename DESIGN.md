## Brand & Style

This design system expresses an elite, cognitive sanctuary tailored for high-achieving university scholars and researchers. It marries the disciplined structure of traditional academic rigor with futuristic AI intelligence. The visual language evokes a state of deep, distraction-free focus ("flow state") late at night in a high-tech library.

The aesthetic fuses **Modern Glassmorphism** with **Deep-Space Minimalism**:
- Translucent, stratified structural planes over near-black cosmic obsidian canvas tones.
- Luminescent indigo-to-violet energetic conduits that signal AI cognition, synthesis, and key actions.
- Precision cyan accents that evoke telemetry, logic verification, and clarity.
- Crisp optical margins, razor-sharp 1px crystalline boundaries, and diffused ambient lighting that give floating surfaces physical presence without visual clutter.

## Colors

The palette establishes an ultra-deep visual environment optimized for eye longevity during extended study sessions. 

### Foundation Surfaces
- **Canvas Base (`#070913`)**: The absolute background layer, anchoring viewport canvas edges.
- **Surface Level 1 (`#0D1126`)**: Sidebar navigation, canvas sub-regions, and base structural panels.
- **Surface Level 2 (`#121833`)**: Resting cards, contextual menus, modal substrates, and module docks.
- **Surface Elevated / Glass (`rgba(255, 255, 255, 0.04)`)**: Translucent top-tier planes requiring `backdrop-filter: blur(16px)`.

### Chromatic Energies
- **Primary Indigo/Violet (`#6366F1` transitioning to `#8B5CF6`)**: Applied to primary CTAs, active AI processing states, knowledge node highlights, and key focus rings.
- **Secondary Cyan/Teal (`#06B6D4` / `#14B8A6`)**: Denotes real-time intelligence feeds, citation verification, mastery percentages, and active research telemetry.
- **Tertiary Amber (`#F59E0B`)**: Reserved for critical deadlines, spaced repetition alerts, system notices, and academic milestones.

### Structural Delimiters & Typography
- **Glass Hairline Borders (`rgba(255, 255, 255, 0.08)`)**: Provides 1px edge definition against dark depths.
- **High-State Border (`rgba(99, 102, 241, 0.3)`)**: Highlights focused or active interface elements.
- **Text Primary (`#F8FAFC`)**: High-contrast, optical clarity for primary readings and titles.
- **Text Secondary (`#94A3B8`)**: Mid-tier metadata, labels, and citations.
- **Text Muted (`#475569`)**: Structural cues, timestamps, and inactive iconography.

## Typography

The typographic hierarchy balances structural presence with academic utility:

- **Display & Headings (Plus Jakarta Sans)**: Contemporary geometry with humanist balance, conveying technical authority. Tight negative tracking gives titles compact, solid weight.
- **Longform Body & Knowledge Streams (Inter)**: Built specifically for extended digital reading. Neutral, open apertures ensure complex formulas, dense citations, and AI-generated syntheses remain effortless to read in dark mode.
- **Contextual Monospace / Meta**: Where mathematical formulations, citations, or prompt variables occur, apply system monospaced alternates paired proportionally with `body-sm`.
- **Label & Action Elements (Plus Jakarta Sans)**: Crisp medium and semi-bold weights improve tap-target recognizability and information scannability.

## Layout & Spacing

The layout is built around a rigorous 8px spatial grid with fluid, responsive columns that adapt across three primary viewport tiers:

- **Desktop (1200px+)**: 12-column layout with 24px/32px gutters and 48px outer canvas margins. Features an asynchronous tripartite structure: persistent left command bar (nav + workspace switcher), fluid primary studio workspace, and collapsible right AI contextual copilot dock (360px–420px).
- **Tablet (768px – 1199px)**: 8-column layout with 24px gutters and 24px margins. Navigation condenses to an icon-rail, and the copilot collapses into a slide-over glass drawer.
- **Mobile (< 768px)**: 4-column layout with 16px gutters and 16px margins. Content stacks vertically; global actions convert to a floating, blurred glass bottom deck.

Rhythmic layout discipline demands that UI containers strictly apply `space-md` (16px) or `space-lg` (24px) internal cushioning to prevent cognitive overwhelm. Complex data modules and study flashcard environments prioritize generous whitespace, preventing mental friction.

## Elevation & Depth

Visual hierarchy does not use physical drop shadows. Instead, it relies on light transmission, surface layering, and luminous boundary halos:

- **Base Ground (`#070913`)**: Level 0. Absorbs background clutter; non-interactive backdrop.
- **Stratified Glass Surface**: Level 1. Background `rgba(13, 17, 38, 0.7)` combined with `backdrop-filter: blur(16px)` and a precise top/side border `1px solid rgba(255, 255, 255, 0.08)`.
- **Floating Overlays & Dialogs**: Level 2. Background `rgba(18, 24, 51, 0.85)` with `backdrop-filter: blur(24px)`. Rim-lit using an ultra-subtle top gradient border (`rgba(255, 255, 255, 0.15)` to `rgba(255, 255, 255, 0.03)`).
- **Luminescent AI Focus Halo**: Elements activated by machine reasoning or active user selection emit an internal ambient glow: `box-shadow: 0 0 32px -4px rgba(99, 102, 241, 0.18), 0 0 0 1px rgba(99, 102, 241, 0.4)`.
- **Depth Contrast Rule**: Deeper panels receive less light and blur. Topmost layers receive higher opacity, brighter 1px border lines, and faint indigo back-glows.

## Shapes

The design system uses a Level 2 (`roundedness: 2`) shape language, balancing soft ergonomics with technical precision:

- **Cards & Workspace Modules**: Use `rounded-2xl` (1.5rem / 24px) to soften analytical density and create a friendly, inviting workspace.
- **Input Fields, Toolbars, & Secondary Modules**: Use `rounded-lg` (0.75rem / 12px) to maintain structured lines within nested layouts.
- **Badges, Status Chips, & Primary Action Buttons**: Use full-pill rounding (`rounded-full` / 9999px) for clear tactile affordance, signaling interactability and smooth continuity.

## Components

### Buttons
- **Primary AI Action**: Gradient fill (`linear-gradient(135deg, #6366F1 0%, #8B5CF6 100%)`), text `#FFFFFF`, rounded full-pill. Rim highlight `inset 0 1px 0 rgba(255, 255, 255, 0.25)`. Hover state triggers a subtle violet bloom (`box-shadow: 0 0 20px rgba(99, 102, 241, 0.4)`).
- **Secondary / Ghost Glass**: Background `rgba(255, 255, 255, 0.04)`, border `1px solid rgba(255, 255, 255, 0.08)`, text `#F8FAFC`. Hover brings background to `rgba(255, 255, 255, 0.08)` and border to `rgba(99, 102, 241, 0.4)`.

### Cards & Knowledge Modules
- Structured on `rounded-2xl` geometry. 
- Background: `rgba(18, 24, 51, 0.6)` with backdrop blur `16px`.
- Border: `1px solid rgba(255, 255, 255, 0.06)`. Hover state introduces a subtle top edge gleam: border transitions to `rgba(255, 255, 255, 0.15)`.

### Pills & Academic Badges
- Pill-shaped (`rounded-full`), padded `4px 12px`.
- **AI Verification Badge**: Background `rgba(6, 182, 212, 0.1)`, border `1px solid rgba(6, 182, 212, 0.3)`, text `#06B6D4`, font `label-caps`. Includes a 6px glowing indicator dot.
- **Urgent / Spaced Repetition Badge**: Background `rgba(245, 158, 11, 0.1)`, border `1px solid rgba(245, 158, 11, 0.3)`, text `#F59E0B`, font `label-caps`.

### Input Fields & Prompt Terminals
- Deep inset background `rgba(7, 9, 19, 0.6)`, border `1px solid rgba(255, 255, 255, 0.08)`, radius `rounded-lg` (12px).
- Placeholder text in `#475569`, active text `#F8FAFC`.
- Focus state: Border transitions to `#6366F1` with an outer glow: `box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.15)`.

### Checkboxes & Segmented Radios
- Size: 18px x 18px, `rounded-md` (4px). Background `rgba(255, 255, 255, 0.04)`, border `1px solid rgba(255, 255, 255, 0.2)`.
- Checked state: Solid `#6366F1` with a crisp white tick mark and a micro-glow halo.

### Specialized Study Components
- **AI Flashcards**: Flippable glass surfaces with `rounded-2xl` borders. Flipping uses a 3D perspective transition with active cyan/indigo edge illumination on the reverse answer surface.
- **Citation Anchors**: Inline interactive tags with `rgba(99, 102, 241, 0.15)` backgrounds that trigger instant glass popover cards with source metadata when hovered.
